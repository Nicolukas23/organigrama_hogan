💡
Concepto clave: Supabase es la fuente de verdad. Los tableros HTML cargan data de Supabase al abrirse. Si Supabase falla, usan la data embebida como fallback.

Cómo se conectan los tableros

Cada tablero HTML tiene un "cargador Supabase" — un bloque de código JavaScript que:

1 Hace fetch a Supabase con la anon key
→
2 Reconstruye la variable global (RAW/DATA)
→
3 Re-renderiza la tabla/gráficos

Los cargadores están identificados con el comentario // ── CARGADOR SUPABASE ──.

⚠️
Importante: Al editar un tablero, respetar que let RAW / let DATA y mantener el cargador. NO convertirlo a const ni borrarlo.

Patrón de carga de datos

// ── CARGADOR SUPABASE ──
let RAW = [];  // ⚠️ NUNCA usar const

async function loadData() {
  try {
    // 1. Fetch de Supabase (data viva)
    const { data } = await supabase.from('table').select('*');
    RAW = data;
  } catch(e) {
    // 2. Fallback: data embebida en el HTML
    RAW = WINDOW_EMBEDDED_DATA;
  }
  render();  // 3. Re-renderizar
}

Generación de PDFs

Usa html2canvas + jsPDF. El flujo es:

  1. Genera HTML del informe (diseño replicado del tablero)
  2. Crea un <div> oculto en el DOM
  3. Renderiza con html2canvas a canvas
  4. Convierte canvas a PDF con jsPDF (A4, multi-página si es necesario)
  5. Descarga via <a> temporal con blob URL

🔄 Cómo Actualizar

Guía paso a paso para actualizar cada tablero.

🚀
Método automático: Usa el Sync Hub (app Streamlit) para actualizar todo con un clic. Ver sección Sync Hub.

Método manual (cuando el Sync Hub no es opción)

Paso 1: Recibir Excels

Recibe de tu compañera:

  • Info Ficha Talento 1.xlsx (INFORMACION, Formación, Desempeño 2024/2025)
  • Info Ficha Talento 2.xlsx (Desempeño 2026, Talentos, 360, Clima)
  • PARTICIPANTES NINE BOX (22).xlsx (observaciones)
  • Planta_de_Personal_Mayo_2026.xlsx (Planta Claro)

Paso 2: Sync a Supabase

node sync_supabase.js # sincroniza todo (~3-5 min)
node sync_supabase.js --tabla=personas # solo una tabla

Lee los Excels y hace upsert a 8 tablas Supabase.

Paso 3: Regenerar ficha_data.js

node rebuild_ficha.js

Genera ficha_data.js desde los Excels. Tarda ~1-2 min.

Paso 4: Actualizar Hogan

node rebuild_hogan_final.js

Actualiza la sección Hogan en ficha_data.js.

Paso 5: Sync tableros HTML

node sync_tableros.js

Sube la data embebida de ninebox/practicantes/hogan/index/organigrama a Supabase.

Paso 6: Git push

git add .
git commit -m "Sync: actualización de datos"
git push origin main

GitHub Pages se actualiza automáticamente en ~2-5 min.

Diferencia UPSERT vs DELETE ALL + INSERT

UPSERT
Actualiza filas existentes, inserta nuevas. Respeta filas que no cambiaron.
DELETE ALL + INSERT
Borra todo y re-inserta. Usado para tablas planas (360, clima) donde no hay key única.

🔧 Troubleshooting

Soluciones a problemas comunes.

❌ "El tablero no se actualiza"

Causa: Caché del navegador.

Solución: Cmd+Shift+R (Mac) o Ctrl+Shift+R (Windows). O abrir en ventana incógnita.

❌ "No carga la data de Supabase"

Causa: Supabase caído o problema de red.

Solución: Verificar status.supabase.com. Los tableros usan data embebida como fallback.

❌ "El PDF se ve feo / muy grande"

Causa: Scale de html2canvas.

Solución: Verificar que htmlToPdf use scale: 1.2 (no 1.6 o 2.0).

❌ "No se descarga el segundo PDF (Hogan)"

Causa: El navegador bloquea la segunda descarga.

Solución: Verificar que _triggerDownload cree un <a> nuevo por cada descarga (no reutilizar).

❌ "Sync Hub no conecta a Supabase"

Causa: Falta el service key en los secrets de Streamlit.

Solución: Verificar SUPABASE_SERVICE_KEY en Streamlit Cloud → Settings → Secrets.

❌ "Git push pide contraseña"

Causa: Token expirado o remote con token.

Solución: Generar nuevo PAT en github.com/settings/tokens (scope: repo).

❌ "Contador Nine Box no es 377"

Causa: Se agregaron personas sin eliminar las que salieron.

Solución: Verificar que personas con caja 0 que no son jefe de nadie estén eliminadas. Ver lista de expedientes retirados en la sección Nine Box.
